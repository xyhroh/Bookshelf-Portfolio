Drop this paper's page images directly in this folder — jpg, png, jpeg,
or webp.

Name them so they sort in the order you want them read, e.g.:
  1.png
  2.png
  3.png

The first image becomes the paper's thumbnail lying in the drawer; click
it to flip through every page. The folder name becomes the paper's
title. They'll show up automatically next time you run "npm run dev"
(or refresh, if it's already running) — no code changes needed.

Add more papers by adding more folders here, one per paper — each
sibling folder of "Paper One" becomes its own paper in the drawer.
