Drop this book's cover artwork here as a single PNG (or jpg/jpeg/webp).

Lay it out as one flat, unfolded book jacket, left to right:

  [ back cover | spine | front cover ]

- The back and front cover panels should be equal width.
- The spine strip in the middle should be narrower than either cover
  panel (it wraps the thin edge of the book).
- The image height should just be the full height of the cover — no
  need to slice anything yourself, the app cuts the three panels apart
  and wraps them onto the book automatically.

If this folder is empty, the book falls back to a plain-colored cover
with the folder name printed on the spine.
